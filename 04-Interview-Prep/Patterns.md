# 🎯 Top 15 Problem Solving Patterns for Coding Interviews

Mastering these 15 core patterns allows you to solve 80%+ of LeetCode Medium/Hard questions:

| # | Pattern | Common Use Cases | Example Problems |
|---|---|---|---|
| 1 | **Two Pointers** | Sorted arrays, palindrome check, pair sums | *2Sum II, 3Sum, Container With Most Water* |
| 2 | **Sliding Window** | Subarray max/min sum, longest substring | *Longest Substring Without Repeating Chars* |
| 3 | **Fast & Slow Pointers** | Cycle detection in LinkedList/Arrays | *LinkedList Cycle II, Happy Number* |
| 4 | **Merge Intervals** | Overlapping ranges, interval scheduling | *Merge Intervals, Insert Interval* |
| 5 | **Cyclic Sort** | Numbers in a range `1` to `N` | *Missing Number, Find All Duplicates* |
| 6 | **In-place Reversal of LinkedList** | Reversing sublists | *Reverse LinkedList II, Reverse Nodes in k-Group* |
| 7 | **Tree BFS (Level Order)** | Shortest path in unweighted tree | *Binary Tree Level Order Traversal* |
| 8 | **Tree DFS** | Path sums, tree height, LCA | *Path Sum II, Lowest Common Ancestor* |
| 9 | **Two Heaps** | Median calculation in stream | *Find Median from Data Stream* |
| 10 | **Subsets & Backtracking** | Combinations, Permutations | *Subsets, Permutations, N-Queens* |
| 11 | **Modified Binary Search** | Rotated sorted array, search space | *Search in Rotated Sorted Array* |
| 12 | **Top K Elements** | Kth largest/frequent items | *Kth Largest Element in an Array* |
| 13 | **K-way Merge** | Merging K sorted lists/matrices | *Merge K Sorted Lists* |
| 14 | **0/1 Knapsack (DP)** | Subsets with target sum constraint | *Partition Equal Subset Sum* |
| 15 | **Topological Sort (Graph)** | Dependency ordering, cycle in DAG | *Course Schedule I & II* |
