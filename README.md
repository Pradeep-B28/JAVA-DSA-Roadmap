## 🚀 4-Phase Curriculum Overview

### Phase 1: Core Java Foundations (`01-Core-Java/`)
- 💡 **Java Syntax & Basics**: Data types, variables, control flow, loops (`Basics.java`)
- 🏗️ **Object-Oriented Programming**: Interfaces, abstract classes, encapsulation (`OOPsDemo.java`)
- 📦 **Collections Framework**: `List`, `Set`, `Map`, `Queue`, `PriorityQueue` (`CollectionsGuide.java`)

### Phase 2: Data Structures (`02-Data-Structures/`)
- ⚡ **Arrays & Strings**: Two Pointers, Sliding Window technique (`ArrayOperations.java`)
- 🔗 **Linked Lists**: Singly & Doubly List operations, cycle detection (`LinkedListDemo.java`)
- 🌲 **Trees & BST**: Traversals (Preorder, Inorder, Postorder, BFS Level-Order) (`BinaryTreeDemo.java`)
- 📊 **Heaps & Hash Tables**: Min/Max Heaps, HashMap frequency counter

### Phase 3: Algorithms (`03-Algorithms/`)
- 🔎 **Searching & Sorting**: Binary Search $O(\log N)$, Merge Sort $O(N \log N)$ (`SortingAlgorithms.java`)
- 🔄 **Recursion & Backtracking**: Decision trees, state space search
- 🧠 **Dynamic Programming**: Overlapping subproblems, state transitions

### Phase 4: Interview Preparation (`04-Interview-Prep/`)
- 🎯 **[Top 15 Problem Solving Patterns](04-Interview-Prep/Patterns.md)**: Sliding Window, Two Pointers, Fast & Slow Pointers, Monotonic Stack, Top-K, etc.
- 📝 **[100+ Essential LeetCode Practice Checklist](04-Interview-Prep/Problem-Set.md)**: Categorized Easy, Medium, and Hard problem lists.

## 🛠️ How to Compile & Run Code Locally

All Java files in this repository are standalone, compilable Java source files.

```bash
# Clone the repository
git clone https://github.com/Pradeep-B28/JAVA-DSA-Roadmap.git
cd JAVA-DSA-Roadmap

# Compile and run Phase 1: Fundamentals
javac 01-Core-Java/01-Fundamentals/Basics.java
java 01-Core-Java/01-Fundamentals/Basics

# Compile and run Data Structures: Binary Tree
javac 02-Data-Structures/04-Trees-and-BST/BinaryTreeDemo.java
java 02-Data-Structures/04-Trees-and-BST/BinaryTreeDemo
```
